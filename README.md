# codex-imagegen-mcp

An MCP server that generates PNG images via OpenAI Codex's built-in `$imagegen` skill and exposes them to Claude Code (and any MCP-compatible client) over stdio.

## What it does

`codex-imagegen-mcp` wraps the `codex` CLI as an MCP tool server. It provides three tools:

| Tool | Description |
|---|---|
| `generate_image` | Generate a PNG from a text prompt and save it to a given path |
| `check_codex` | Report whether `codex` is installed, its version, and login status |
| `list_recent` | List images recently generated by this server |

## Prerequisites

- [Codex CLI](https://github.com/openai/codex) installed and on `$PATH` (or set `CODEX_BIN`)
- `codex login` completed (requires an OpenAI account)
- Go 1.26+ (to build from source)

## Build

```bash
git clone https://github.com/gfranks/codex-imagegen-mcp
cd codex-imagegen-mcp
go build -o codex-imagegen-mcp .
```

## Environment variables

| Variable | Default | Description |
|---|---|---|
| `CODEX_BIN` | `codex` | Path to the codex CLI binary |
| `CODEX_IMAGEGEN_SESSIONS_DIR` | `~/.codex/sessions` | Where codex stores its session rollouts |
| `CODEX_IMAGEGEN_IMAGES_DIR` | `~/.codex/generated_images` | Where newer Codex versions store generated PNG files |
| `CODEX_IMAGEGEN_TIMEOUT` | `180s` | Max time to wait for a single image generation |
| `CODEX_IMAGEGEN_DANGEROUSLY_BYPASS_SANDBOX` | `false` | When `true`, pass `--dangerously-bypass-approvals-and-sandbox` to Codex |
| `CODEX_IMAGEGEN_MANIFEST` | `~/.codex-imagegen-mcp/manifest.jsonl` | JSONL file for recent-images tracking |
| `CODEX_IMAGEGEN_DEFAULT_EFFORT` | `low` | Default reasoning effort (minimal/low/default/medium/high/xhigh) |
| `CODEX_HOME` | _(unset)_ | Override codex home directory |

## Tools

### `generate_image`

Generate a PNG image from a text prompt using Codex's `$imagegen` skill.

**Required inputs:**

- `prompt` (string) — the image description
- `out` (string) — file path to write the PNG to (absolute, or relative to the server's working directory)

**Optional inputs:**

- `effort` (string) — reasoning effort: `minimal`, `low`, `default`, `medium`, `high`, or `xhigh`. Codex model selection is always delegated to the authenticated Codex account default.
- `workdir` (string) — codex working directory; defaults to a temp dir
- `reference_images` (string[]) — local file paths of reference images to attach as vision input. Images are sent to the model via codex's `-i` flag as actual image tokens, not merely mentioned in the prompt. All paths are validated to exist before codex runs.
- `aspect_ratio` (string) — best-effort aspect ratio hint (e.g. `16:9`, `1:1`, `4:3`). Translated into framing guidance in the prompt. The built-in image generation tool does not accept an explicit size parameter, so this is advisory only.

**Example:**
```json
{
  "name": "generate_image",
  "arguments": {
    "prompt": "a sunset over rolling hills in watercolor style",
    "out": "/tmp/sunset.png",
    "effort": "low"
  }
}
```

**Example with reference images:**
```json
{
  "name": "generate_image",
  "arguments": {
    "prompt": "a dragon perched on a cliff in the style of the reference images",
    "out": "/tmp/dragon.png",
    "reference_images": ["/tmp/style-ref-1.png", "/tmp/style-ref-2.png"],
    "aspect_ratio": "16:9"
  }
}
```

The response includes a `reference_images` field echoing back the paths that were attached as vision input.

### `check_codex`

Report whether the `codex` CLI is installed, its version, and whether it is logged in.

**No inputs required.**

**Example response:**
```json
{
  "codex_installed": true,
  "version": "codex-cli 0.144.1",
  "logged_in": true,
  "sessions_dir": "/Users/you/.codex/sessions"
}
```

### `list_recent`

List images recently generated by this server (path, prompt, dimensions, timestamp).

**Optional inputs:**

- `limit` (integer) — max number of recent images to return (default 10)

**Example:**
```json
{
  "name": "list_recent",
  "arguments": { "limit": 5 }
}
```

## Claude Code MCP registration

Add to your Claude Code MCP config (`.claude/mcp.json` or equivalent):

```json
{
  "mcpServers": {
    "codex-imagegen": {
      "command": "/Users/gfranks/workspace/codex-imagegen-mcp/codex-imagegen-mcp"
    }
  }
}
```

Then restart Claude Code. The three tools will appear as `mcp__codex-imagegen__generate_image`, `mcp__codex-imagegen__check_codex`, and `mcp__codex-imagegen__list_recent`.
